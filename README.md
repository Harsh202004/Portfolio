# Harsha Hutagi Portfolio

Personal portfolio website for Harsha Hutagi, a final-year Computer Science and Engineering student focused on full-stack development, Android engineering, AI-powered applications, and clean user interfaces.

## Overview

This is a static single-page portfolio built with plain HTML, CSS, and JavaScript in `index.html`. It includes:

- Hero section with profile image and floating badges
- Skills, projects, about, certifications, and contact sections
- Theme switcher for dark, light, and techy modes
- Clickable certification cards with an in-page certificate viewer
- Resume PDF and certificate assets

## Project Structure

```text
.
+-- index.html
+-- Harsha_Hutagi_Resume.pdf
+-- images/
    +-- gallery/
        +-- certificate-aws-simplilearn.png
        +-- certificate-cdac-security.png
        +-- certificate-illinois-tech.png
        +-- Cloud Certificate.pdf
        +-- professional.jpeg
```

## Run Locally

Open `index.html` directly in a browser.

No build step or package installation is required.

## Certificates

Certificate files are stored in `images/gallery/`. The certification cards in `index.html` use `data-cert-src` attributes to open the matching image or PDF in the built-in viewer.
